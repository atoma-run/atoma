# Documentation archive

[Current documentation](../README.md) · [Code review index](../code-reviews.md)

These records preserve earlier designs, experiments, reviews and release
evidence. Their dates, statuses, rejected alternatives and measured results
belong to the original work. Some accepted decisions remain applicable;
archiving records changes their location, not their authority. Consult the
current guides and subsystem `AGENTS.md` contracts before using them as an
operating procedure.

Filenames are retained so historical citations remain searchable. Relative
links and repository citations have been adjusted to the new locations;
machine-readable receipts are preserved unchanged. The frozen engineering
record in `../incidents/` retains its original inline paths.
