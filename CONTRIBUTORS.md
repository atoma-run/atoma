# Contributors

Thank you to everyone helping build atoma.

## Add your name

Add one entry to the list below using this format:

```markdown
- [Your name](https://github.com/your-username)
```

Please add only yourself, or someone who has agreed to be listed. Read
[CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process and CLA.

This file is a community list. GitHub's automatic **Contributors** list is
based on commit authorship on the default branch (`main`). To receive credit,
author your change using an email linked to your GitHub account and have it
merged into `main`.

If a maintainer commits a change you helped author, they can credit you with
a commit trailer, separated from the message body by a blank line:

```text
Co-authored-by: Your name <your-github-linked-email>
```

Use the email associated with your GitHub account, including your GitHub
`noreply` address if you prefer to keep your personal email private. Adding
a name to this file alone does not add that person to GitHub's Contributors
list.
